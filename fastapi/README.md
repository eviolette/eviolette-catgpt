# CatGPT API Documentation

This FastAPI application provides three LLM-powered endpoints for different response types using an `OpenAIClient`. It supports Markdown, Python code, and JSON responses based on user prompts.

---

## Base URL

```
http://localhost:8081
```

---

## Input Schema

All endpoints accept the following **JSON payload** as input:

```json
{
  "prompt": "string",           // The user prompt to send to the LLM
  "system": "string (optional)" // Optional system-level instruction (default: 'You are a helpful assistant.')
}
```

---

## Endpoints

### 1. POST `/markdown`

**Description:**  
Returns a markdown response for a given prompt using the LLM.

**Request:**
- Content-Type: `application/json`
- Body: PromptRequest (as defined above)

**Response:**
```json
{
  "type": "markdown",
  "content": "string"
}
```

---

### 2. POST `/python`

**Description:**  
Returns raw Python code (fenced markdown removed) for the given prompt using the LLM.

**Request:**
- Content-Type: `application/json`
- Body: PromptRequest

**Response:**
```json
{
  "type": "python",
  "content": "string"
}
```

---

### 3. POST `/json`

**Description:**  
Returns a JSON-formatted response generated by the LLM.

**Request:**
- Content-Type: `application/json`
- Body: PromptRequest

**Response:**
```json
{
  "type": "json",
  "content": { "key": "value", ... }
}
```

---

## CORS Configuration

This API allows CORS requests from:

- `http://localhost:8000`
- `http://localhost:80`

This ensures compatibility with local React applications during development.

---

## Notes

- The app uses a custom `OpenAIClient` class loaded from `configs/openai_config.yaml`.
- All LLM responses are generated using methods like `get_text`, `get_python`, and `get_json`.
- Error responses return status code `500` with the error message.

---

## Example Request (Curl)

```bash
curl -X POST http://localhost:8081/python \
  -H "Content-Type: application/json" \
  -d '{ "prompt": "Write a function to reverse a string in Python." }'
```
